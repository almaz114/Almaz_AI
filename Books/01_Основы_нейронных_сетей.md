# 1. Что такое нейронная сеть

Нейронная сеть — это математическая модель, состоящая из множества связанных вычислительных элементов — **искусственных нейронов**.

Она получает входные данные, выполняет над ними последовательность математических преобразований и формирует результат.

Упрощённо:

```text
Входные данные
      ↓
Нейронная сеть
      ↓
Предсказание / решение
```

Например:

```text
Изображение → нейросеть → "кошка"
Текст       → нейросеть → продолжение текста
Данные      → нейросеть → прогноз
Светофор    → нейросеть → идти / стоять
```

Самое важное: поведение сети не обязательно задаётся программистом набором правил `if/else`. Во время обучения сеть **подбирает значения своих параметров**, чтобы её ответы становились ближе к правильным.

---

# 2. Аналогия с биологическим нейроном

Идея искусственного нейрона исторически вдохновлена работой биологических нейронов.

Очень грубая аналогия:

```text
Биологический нейрон        Искусственный нейрон

Входящие сигналы      →     Входные значения
Сила соединений       →     Веса
Обработка сигналов    →     Математическая сумма
Реакция нейрона       →     Выход
```

Это только учебная аналогия. Искусственный нейрон — не цифровая копия настоящей нервной клетки, а математическая конструкция.

---

# 3. Искусственный нейрон

Представим нейрон с тремя входами:

```text
x₁ ── w₁ ─┐
x₂ ── w₂ ─┼──► Σ ──► + bias ──► activation ──► output
x₃ ── w₃ ─┘
```

Каждый вход имеет свой вес.

В упрощённой математической форме:

\[
z = x_1w_1 + x_2w_2 + x_3w_3 + b
\]

После этого значение `z` может пройти через функцию активации:

\[
a = f(z)
\]

где:

- `x` — входные значения;
- `w` — веса;
- `b` — bias, или смещение;
- `f` — функция активации;
- `a` — выход нейрона.

### Что такое вес

Вес показывает, насколько сильно конкретный вход влияет на результат нейрона.

Большой положительный вес усиливает влияние сигнала. Отрицательный вес может изменить направление его влияния. Маленький вес делает влияние слабым.

### Что такое bias

`Bias` — дополнительный обучаемый параметр. Он позволяет сдвигать результат вычисления и делает нейрон более гибким.

### Что такое функция активации

Функция активации преобразует вычисленный сигнал перед его передачей дальше.

Пока достаточно запомнить:

> **Функция активации помогает нейросети моделировать сложные нелинейные зависимости.**

Подробно `ReLU`, `Sigmoid`, `Tanh` и `Leaky ReLU` разберём в **главе 2**.

# 4. Как несколько нейронов образуют сеть

Один нейрон решает очень ограниченную задачу. Поэтому нейроны объединяются в **слои**.

Упрощённая сеть:

```text
ВХОДНОЙ СЛОЙ       СКРЫТЫЙ СЛОЙ       ВЫХОДНОЙ СЛОЙ

   x₁  ● ───────┐      ●
                 ├────►● ────────┐
   x₂  ● ───────┤      ●          ├────► ●  результат
                 ├────►● ────────┘
   x₃  ● ───────┘      ●
```

### Входной слой

Получает исходные признаки.

Для светофора это могут быть три значения:

```text
Красный
Жёлтый
Зелёный
```

### Скрытый слой

Промежуточные нейроны преобразуют входную информацию.

Скрытых слоёв может быть много.

### Выходной слой

Формирует итоговый результат.

В нашем учебном примере:

```text
0 → стоять
1 → идти
```

# 5. Как информация проходит через сеть — Forward Pass

Когда мы передаём данные в сеть, они проходят от входа к выходу.

Этот процесс называется **Forward Pass**.

```text
Вход
 ↓
Первый слой
 ↓
Активация
 ↓
Следующий слой
 ↓
...
 ↓
Выход
 ↓
Предсказание
```

Например:

```text
[красный=0, жёлтый=0, зелёный=1]
                  ↓
             нейросеть
                  ↓
                0.94
                  ↓
              ИДТИ
```

На этом этапе сеть только вычисляет ответ. Она ещё ничего не исправляет.

# 6. Что означает «обучить нейросеть»

В начале обучения веса сети обычно ещё не настроены для нашей задачи.

Поэтому сеть может отвечать неправильно.

Предположим:

```text
Правильный ответ: 1.0
Ответ сети:       0.23
```

Нам нужно определить, насколько ответ плох.

Для этого используется **Loss Function**.

После вычисления ошибки сеть получает информацию о том, как нужно изменить параметры, чтобы уменьшить эту ошибку.

Общий цикл:

```text
Данные
  ↓
Forward Pass
  ↓
Предсказание
  ↓
Сравнение с правильным ответом
  ↓
Loss
  ↓
Backpropagation
  ↓
Gradient
  ↓
Optimizer изменяет веса
  ↓
Повторяем
```

Этот цикл может повторяться много раз.

---

# 7. Loss — насколько сильно ошиблась сеть

`Loss` — числовая оценка ошибки модели.

Условно:

```text
Loss = большой
→ сеть ошибается сильно

Loss = маленький
→ ответы ближе к правильным
```

Сам по себе Loss не обучает сеть. Он даёт математическую величину ошибки, на основе которой затем вычисляются градиенты.

Подробно Loss будет разобран в отдельной главе.

---

# 8. Backpropagation и Gradient

После вычисления ошибки нужно определить:

> Какие параметры сети и в какую сторону следует изменить?

Для этого используется **обратное распространение ошибки — Backpropagation**.

Градиенты показывают, как изменение конкретного параметра влияет на Loss.

Пока достаточно такой картины:

```text
Предсказание оказалось неправильным
                ↓
       вычислили Loss
                ↓
     пошли назад по сети
                ↓
  вычислили влияние параметров
                ↓
      получили градиенты
                ↓
      изменили параметры
```

В следующих главах мы разберём этот процесс значительно подробнее.

# 9. Основные понятия обучения

## Dataset

`Dataset` — набор данных, на которых работает или обучается модель.

Для светофора одна запись может выглядеть так:

```text
[0, 0, 1] → ИДТИ
```

---

## Tensor

`Tensor` — структура числовых данных, с которой работают современные нейросетевые библиотеки.

На первом этапе можно представить tensor как обобщение:

```text
одно число
список чисел
таблица чисел
многомерный массив чисел
```

В PyTorch основной тип называется `torch.Tensor`.

---

## Parameter

`Parameter` — обучаемое числовое значение модели.

Типичные параметры:

```text
веса
bias
```

Во время обучения оптимизатор изменяет именно параметры.

---

## Epoch

Одна **эпоха** означает, что модель один раз прошла через весь обучающий набор данных.

```text
Dataset
  ↓
Epoch 1
  ↓
Epoch 2
  ↓
Epoch 3
  ↓
...
```

---

## Batch

`Batch` — небольшая группа примеров, которая обрабатывается за один шаг обучения.

Например:

```text
Dataset = 10 000 примеров
Batch = 100 примеров
```

Тогда одна эпоха будет состоять примерно из 100 batch-шагов.

---

## Learning Rate

`Learning Rate` определяет величину шага изменения параметров.

Очень грубо:

```text
слишком маленький → обучение медленное

разумный          → обучение устойчивое

слишком большой   → можно перескакивать через хорошее решение
```

---

## Optimizer

Оптимизатор использует вычисленные градиенты для обновления параметров модели.

Например, в PyTorch существуют:

```text
SGD
Adam
AdamW
```

Сейчас достаточно понимать его роль:

> **Optimizer — механизм, который изменяет параметры модели в направлении уменьшения ошибки.**

# 10. Основные виды нейронных сетей

На этом этапе нам не нужно изучать их устройство. Нужно только увидеть общую карту.

### MLP

Классическая полносвязная нейронная сеть.

Подходит для простых учебных задач и табличных данных.

### CNN

Свёрточные нейронные сети особенно известны применением к изображениям.

```text
Изображение → CNN → распознанный объект
```

### RNN

Архитектуры, предназначенные для последовательностей.

Исторически активно использовались для текста, речи и временных рядов.

### Transformer

Архитектура, лежащая в основе большинства современных больших языковых моделей.

```text
Текст
 ↓
Transformer
 ↓
Продолжение / ответ
```

Позже мы подробно дойдём до:

```text
Token
 ↓
Embedding
 ↓
Attention
 ↓
Transformer
 ↓
LLM
```

# 11. 🌍 Наш жизненный пример — светофор

Теперь свяжем теорию с очень простой понятной задачей.

У светофора есть три сигнала:

```text
🔴 Красный
🟡 Жёлтый
🟢 Зелёный
```

Мы хотим, чтобы модель принимала решение:

```text
СТОЯТЬ
или
ИДТИ
```

Правила учебного примера:

| Красный | Жёлтый | Зелёный | Решение |
|---:|---:|---:|---|
| 0 | 0 | 0 | Стоять |
| 0 | 0 | 1 | Идти |
| 0 | 1 | 0 | Стоять |
| 0 | 1 | 1 | Идти |
| 1 | 0 | 0 | Стоять |
| 1 | 0 | 1 | Стоять |
| 1 | 1 | 0 | Стоять |
| 1 | 1 | 1 | Стоять |

Главное правило:

> 🔴 **Если присутствует красный сигнал — стоим.**

Если красного нет:

> 🟢 **Если присутствует зелёный — идём.**

В остальных случаях:

> **Стоим.**

Это искусственный учебный пример, а не описание реальных правил дорожного движения.

# 12. Как представить светофор числами

Компьютеру удобнее работать с числами.

Поэтому:

```text
выключен = 0
включён = 1
```

Состояние:

```text
🔴 выключен
🟡 выключен
🟢 включён
```

становится:

```text
[0, 0, 1]
```

А:

```text
🔴 включён
🟡 выключен
🟢 включён
```

становится:

```text
[1, 0, 1]
```

Результат тоже представим числом:

```text
0 = СТОЯТЬ
1 = ИДТИ
```

Мы превратили понятную человеку задачу в набор числовых примеров.
